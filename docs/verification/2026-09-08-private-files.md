## 覆盖及证据边界

测试用本地 HTTP 服务读取临时目录中的真实文件，核对完整文件/Range 的字节和响应头；这不是 Supabase 云端。策略测试在真实 PostgreSQL 的最小 storage 模型中执行实际配置 SQL，证明 restrictive 策略能压过已有宽松策略，不能代替真实 Supabase 服务端验收。

- 权限不通过、不存在及无效范围不触发对象读取；公开桶拒绝；任意路径、远程明文连接和覆盖上传拒绝。
- HTML/SVG 强制下载；文件名和上游不安全响应头不透传。
- 使用实际受限数据库连接读取已发布 OPS 附件；角色降为 Support 后同一链接拒绝且不读文件；归档拒绝；新草稿保留旧正式文件可读；发布不含旧附件的新正式版本后旧链接拒绝。
- 文件备份包含实际字节并可恢复；本地损坏在上传前被拒绝；恢复后重新读回文件并核对 SHA256。
- 指定私有桶可显式创建、已存在时复用；已有公开桶拒绝。

## 审查与修复
