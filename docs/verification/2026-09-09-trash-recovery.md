# T033 文章删除、回收站与恢复（本地验收）

## 交付范围

管理员可从编辑页把文章移入回收站，在独立回收站恢复为未发布草稿，或输入当前完整标题后永久删除。未保存输入和上传期间禁用删除；服务器另行检查当前 Admin、生命周期和事务序号。待审文章删除会撤回当前审核。恢复保留正文版本，但清空发布、指派与批准指针，需要重新走审核发布。

删除后，既有员工阅读、搜索、私有附件和 PDF 授权均拒绝访问；旧链接不会重新开放文章。永久删除实际移除正文版本及关联业务记录，另保留不可更改的删除凭据和审计元数据，不保留正文。永久删除的文章编号和附件 UUID 不可复用。所有破坏性测试仅操作独立测试资料。

附件清理由持久任务管理。删除正文和删除私有对象不是一个数据库事务；未配置存储、网络失败、确认结果不明、超时或记录完成失败时都保留待处理项，管理员可重试。只有存储确认对象不存在且数据库确认后才减少待处理数量。每轮最多 25 项，共用 20 秒期限；仅实际开始的项目更新尝试时间，未轮到的项目优先留到下一轮。查看回收站和读取数量不会修改清理任务。

## 复核和修复

- 永久记录缺失的清理请求返回 NOT_FOUND，不把不存在的文章误报为附件已清空。
- 删除与新增附件共享按 UUID 排序的事务锁；INSERT 获锁后重新检查永久记录。两条真实受限数据库连接验证“删除尚未提交、同 UUID 上传等待、提交后拒绝复用”的交错，旧任务不会误删新对象。
- 清理尝试时间逐项更新，避免仅有少量任务而前项耗尽期限时，未执行的后项被反复跳过。
- 待上传资产存在时拒绝删除，覆盖正常上传中的文档删除竞态。
- 一般运行账号仍没有任意 DELETE 能力；永久删除仅在已授权函数生成的私有事务上下文内放行不可变历史的删除。迁移所有者的维护例外不用于应用连接；ScopedDatabase 拒绝所有者凭据。

## 尚未验收

Clerk、Supabase、公司邮箱/Slack 允许列表仍未接入真实联合验收；未部署、未做真机验收。本轮没有重跑实际 PDF 生成套件，PDF 访问关闭由数据库权限测试覆盖，先前 PDF 测试不计入本轮成绩。

云端 PUT 超时后是否可能延迟落盘、供应商取消行为，以及异常遗留 pending 上传的人工恢复仍需测试项目验证；目前不能宣称跨数据库和远端存储的原子永久删除。正常 pending 上传会阻止删除，页面说明应按实际错误处理。

Supabase 缺失对象响应按官方实现核对，只有明确的 NoSuchKey/404 语义才视为不存在，权限、桶不存在、矛盾响应和未知格式保留待处理状态。参考：[Storage 错误处理](https://github.com/supabase/storage/blob/master/src/http/error-handler.ts)、[Storage 错误定义](https://github.com/supabase/storage/blob/master/src/internal/errors/storage-error.ts)、[Storage JS 文件接口](https://github.com/supabase/storage-js/blob/master/src/packages/StorageFileApi.ts)。这属于协议实现参考，不是云端验收证据。
