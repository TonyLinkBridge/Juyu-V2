# T022 面包屑、文章翻页与回到顶部：本地验收

日期：2026-09-08

## 已交付

文章顶部显示帮助中心、已授权分类祖先及当前正式标题；帮助中心返回目录，当前文章带aria-current标记。分类目前没有独立页面，显示真实层级文字，不造不存在的分类链接或默认跳去另一篇文章。深层和长中文路径自然换行。

文章底部按员工实际可见目录的深度优先顺序显示上一篇、下一篇；按文章ID去重，不循环，第一篇无上一篇，最后一篇无下一篇，只有一篇时不显示翻页栏。可以跨目录分组继续阅读，顺序与左侧目录一致。卡片保留GitBook的箭头/标签/标题结构，电脑左右排列、窄屏上下排列。

ReaderNavigation只在选中的已授权文章与正式正文匹配时生成pageNavigation投影，使用既有reader同事务快照，不读取管理目录。辅助函数本身不是授权边界，不能传入未筛选数据。链接由文档ID重新生成内部路径，点击后再走原有阅读授权。不存在/无权/下线文章不显示面包屑、翻页或回顶按钮。

回到顶部沿用GitBook按钮处理逻辑，尊重减少动画设置，并将键盘焦点回到文章标题。保留现有URL及章节hash；刷新深链接仍按原章节定位，不会把回到顶部误当成新的文章导航。
