# T021 手机版目录与基础自适应：本地验收

日期：2026-09-08

## 已实现

1024px及以上保留左侧目录；窄屏改成“文章目录”按钮，打开左侧原生 modal dialog。关闭按钮、Escape、点击遮罩、选择文章都会关闭菜单；普通新标签快捷操作不主动关闭。菜单使用同一份服务器已授权目录，没有新增身份来源、数据查询或演示路由。

菜单打开时焦点进入关闭按钮，Tab/Shift+Tab在可见控件首尾循环，折叠分组中的链接不参与；原生modal令背景不可交互。关闭时恢复原滚动位置、原body样式及触发按钮焦点。切回桌面自动释放modal/滚动锁；若菜单原先打开，则聚焦桌面的当前项或目录标题。组件卸载也会恢复滚动样式。

长目录打开时定位当前文章，切回桌面时重新定位，包括菜单从未打开的情况。桌面目录高度扣除现有88px顶部空间，防止末尾文章位于视口下方。不支持原生dialog方法时使用details目录；SSR也输出details作为无脚本回退，真实已登录SSR的无脚本联合验收仍待服务配置。

横屏小高度下，关闭按钮保持可见、目录内部滚动。新增reader-scroll-region宽表格/代码容器CSS和媒体最大宽度约束；表格用1200px排版夹具验证局部横滚、不撑大页面。现阶段没有真实富表格渲染器，该集成仍须后续内容任务验收，不能据此宣称所有富内容已完成。

新增覆盖：关闭/焦点恢复、Tab首尾循环、折叠分组与文章跳转、刷新默认关闭、长目录当前项定位、遮罩关闭、滚动恢复、打开及关闭状态下的桌面切换、横屏低高度、宽表格局部滚动、缺失原生dialog方法回退。

独立代码复核发现并修复：不支持dialog时直接调用close导致回退页面抛错；手机首次加载后切回桌面不重新定位当前项。实际浏览器还发现Shift+Tab从首控件进入浏览器chrome，以及原有100dvh目录加上顶部高度导致末项被裁切。均保留修复前失败证据并通过修复后回归，复核未发现新增可操作问题。原空状态测试改为限定可见导航，避免匹配隐藏的桌面/回退/弹层副本。

本次不改数据库或授权逻辑，没有重跑数据库套件；上一阶段72项数据库检查仅为历史证据。Clerk/Supabase及公司准入配置仍未连接，没有真实账号/云端迁移/部署。真实Safari、手机设备、已登录联合验收及富内容表格测试仍待办。
