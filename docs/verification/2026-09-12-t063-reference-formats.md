# T063-R17 · Reference 格式保留

状态：本地修复和专项验证完成；未推送、未部署、正式账号线上验收待办。

## 原因

readReferenceDetail 原来通过 tableTextGrid 只返回 headers/rows 字符串。
原始正式文章的富文本没有消失，但 Reference 响应及组件没有保留或显示它。

## 修改

- 接口保留经员工阅读解析器校验过的 native 表格结构及表格文字颜色；不携带周边正文、子段落或未发布版本。
- 纯文字投影继续用于筛选；合并区域的标签参与其覆盖行的筛选，不把右边数据挤错列。
- 速查表与文章共用 StructuredInline，保留文字/背景颜色、粗体、斜体、下划线、删除线、代码和安全链接；单元格对齐、列宽、多层表头、行列合并也保留。
- 跨筛选结果或分页的合并单元格只占当前可见行，并在后续页重复来源标签，不修改已发布正文。
- 旧的 Markdown/自定义纯文字表格兼容入口保留；本项没有改造 Reference 整页导航，那个问题另记 R07。
- 没有 SQL 迁移，也没有写入正式内容；服务端授权与发布版本读取未更改。

## 验证

1. 新增数据库回归先失败，明确缺少 native 格式；修复后通过。
2. Reference 筛选/HTTP/合并投影 6/6；原生格式和安全校验 7/7。
3. 本机临时数据库 Reference 12/12：正式版本、权限、撤销、下线、周边正文排除、富文本保留。
4. Reference 桌面/手机交互 8/8：分页、列筛选、合并标签、颜色、链接、对齐、空结果、拒绝状态；新格式测试包含浅色/深色。
5. 编辑器共享格式组件的保存、重开、预览专项 2/2（桌面/手机）。
6. lint、TypeScript、生产构建及 PDF 部署资源检查通过。

共 35 项专项测试通过。浏览器是本地隔离组件样例，数据库是临时测试库，不是正式账号验收。
人工查看 reference-rich-light-desktop.png 与 reference-rich-dark-mobile.png；颜色、表头、合并标签可见，手机表格在自身区域滚动，不撑宽整个页面。
构建仍有既有 preferredRegion 弃用提示；没有把它当作本项失败或顺手改动部署区域。
