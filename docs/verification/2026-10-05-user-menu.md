# Account menu verification — 2026-10-05

Base revision: `9773f5243de2222b1781262f87fb6afc09cbd4a0`. This report records pre-push local verification of the account-menu patch. Deployment and real-account acceptance are not established by these checks.

## Source and integration

The old account menu and its unused styles have been replaced by Elia Kuratli’s MIT-licensed Arc User Menu. See [source provenance and adaptations](../sources/user-menu.md). The original desktop panel, mobile sheet, spacing, radius, motion and focus behavior remain. Source tokens are scoped to the component; JUYU supplies its existing colors and font stack.

The application adapter reads actual Clerk identity, avatar, email and role labels. Account settings opens Clerk’s profile interface. Theme selection shares the existing page provider. Logout retains leave confirmation, local recovery and recent-search cleanup, and current-session redirects. Cancellation or provider failure keeps the menu usable; pending logout prevents duplicate requests. Demo billing, presence and shortcut hints are not configured. Displayed role labels do not change server authorization.

The source’s unsupported `aria-modal` attribute on a menu role was removed. A `ResizeObserver` reruns the source placement logic when provider feedback changes panel height, so a menu above its trigger stays correctly anchored.
