# T039 历史记录、版本查看与恢复（本地验收）

## 范围

管理员从编辑器、二审页、发布页、归档页和回收站进入文章历史。操作记录与正文版本各自分页，每页30条，不把最近20条摘要当成完整历史。记录保留操作者、作者/编辑、指定二审人及改派、退回原因、批准、发布、归档/下线和删除事件。版本预览包含正文、可见范围、分类、标签、封面及所有关联附件。

永久删除记录可从后台和回收站持续查找，包括附件清理完成后的记录。历史来自不可变删除凭据，只展示元数据与操作事件；不提供已永久删除正文、附件或恢复按钮。

恢复只允许有效公司管理员对工作台中较旧版本执行，待审期间先结束审核，归档/回收站先恢复生命周期。操作创建全新草稿，不改写旧版本；复制来源版本的正文、标签、封面、分类、可见范围及全部版本附件，保留原作者，操作人为新版本编辑。当前正式版保持不变，新草稿须重新二审发布。明确确认影响后提交，陈旧页面不能覆盖别人更新。

## 实现和权限

新增0012迁移和来源版本审计字段，保留旧迁移/审计/审核行。恢复命令以成员共享锁、文章编辑锁、资料行锁及当前成员复查保护事务，检查附件就绪并保留精确重试凭据。恢复、版本关联、工作指针和审计在同一事务提交。待处理上传、失效来源附件、异常工作版本和冲突会拒绝恢复。来源文件就绪检查基于本地数据库状态与版本关联，未冒充真实存储的逐个联网回读验收。

历史查看和资源按当前有效Admin检查。图片、影片、文件/PDF原文件走选定文章和版本的私有附件路由；流程图按该历史版本的实际来源生成，生成前后检查权限。员工阅读、搜索和PDF导出继续只使用当前有权正式版。私有响应no-store，存储发送前沿用第二次授权。已传送到设备的字节不可收回。
