## 验收内容

1. 空库创建表，重复迁移保留数据；校验和变更时明确失败。
2. 完整提交、二审、排队、发布、新稿、重新审核发布；新稿期间旧正文持续可读。
3. 改派、退回、重提、撤回保留每轮审核；错误二审人和待审修改拒绝。
4. Support、未验证审核者、自审、已停用成员的非法写入拒绝；管理读取同样检查权限。
5. 编辑和发布各使用两个独立连接；先确认两者都在 PostgreSQL 等待行锁，然后释放锁。每次恰好一个成功，另一个 CONFLICT，无额外版本或历史。
6. 审计插入强制故障后读回核对：新版本、提审记录、状态及正式指针一起回退。
7. 版本与审计禁止更新/删除，跨资料版本指针拒绝；已结束审核不能删掉或改换批准人。
8. 临时无权限 SQL 角色即使获准表 SELECT，RLS 仍不给它读取任何业务行；这不是生产身份策略验收。
9. 在另一全新临时集群移除本次 schema、重新应用成功。此为局部迁移回退重建演练，不是生产备份或数据恢复（T060）。
