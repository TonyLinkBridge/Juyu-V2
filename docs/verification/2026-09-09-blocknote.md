# T031 · BlockNote 编辑器本地验收

日期：2026-09-09。工作目录：`/Users/tony/Documents/ChatGPT/Juyu V2`。对应用户“下一步”、既有设计和 T031 计划；未接 Liveblocks，未连接真实账号或云端。

## 已实现

管理员工作台提供新建文章和完整编辑入口 `/admin/editor`。编辑标题、类型、阅读范围、标签、私有封面与正文；BlockNote 0.54.0 支持段落、三级标题、列表和五种基本文字格式。已有图片、影片、文件、表格、提示、代码、文字标签、公式、流程图作为自定义块插入正文并调整顺序。草稿首存后才开放本篇文件上传，沿用已校验的私有上传与预览接口。

停止输入 1.2 秒后自动保存，也可立即保存。一次只发一个请求；保存中继续输入保留为下一次修改。网络/5xx/无效回执保留未确认请求，手动重试先精确重放，再保存新输入；明确 4xx 拒绝允许修正后重试。未保存离开提醒、复制当前输入、重新载入和草稿阅读预览已接入。字段不合法时保留输入控件与删除操作。

服务端每次验证当前 Admin，锁定文章并核对序号。首次创建使用稳定 UUID；重放必须符合相同作者、完整内容、操作与序号，只返回已有版本。两位管理员并发写入仅一位成功。待审/停用内容拒绝编辑，旧正式版本继续可读；分类、独立附件和历史保持不变。保存成功回执直接来自同一事务，不读其他人的后续版本充当确认。原媒体编辑接口拒绝单独修改结构化正文的媒体投影。

正文通过版本化编码保存在现有不可变 body；content_blocks 为服务端推导的媒体投影，复用附件、图形和 PDF 授权。阅读和 PDF 按同一正文顺序混排，不重复追加媒体。旧正文继续读取；进入编辑时转换既有受支持格式，超限旧表格保留为文字。空白正文可打开；旧标题锚点尽量保留，若与媒体 ID 冲突则仅冲突标题生成新 ID，不丢内容。
