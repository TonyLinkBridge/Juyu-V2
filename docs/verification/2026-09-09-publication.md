# T037 安排发布与正式发布（本地验收）

## 实现范围

二审详情新增“安排与发布”入口，管理员可核对完整保存正文、阅读范围、标签、封面、批准人和批准时间。只有当前有效管理员可以操作：已批准版本先加入等待发布，随后再次明确确认正式发布。不支持绕过批准或跳过等待发布，不提供自动定时上线。

发布时核对同一送审版本的提交人、原提交记录、改派链路及独立二审批准凭据。当前操作者再次通过权限检查；有效的历史批准不会因为批准人后来离职或降级而自动撤销。文章编辑会重走审核，回收站恢复保持T033的未发布草稿规则，不能复用删除前的批准。

安排和发布都会检查上传状态和当前版本的附件、封面、媒体关联。文件必须属于本篇文章且已就绪。正文、工作状态、正式版本指针与操作记录在同一事务中提交；任何一步失败均不留下半次发布。旧正式版在批准和排队期间继续可读，发布成功后阅读与搜索、图片、文件、PDF按新正式版本及其可见范围执行。

界面严格核对操作回执，显示确切的版本替换影响。未确认结果保留原请求用于精确重试并锁住其他操作；明确拒绝要求重新读取。已经确认的操作不会因后续读取失败被说成失败，页面会标明旧快照并暂停新操作。发布历史显示最近20条及是否仍有更早记录，完整历史界面是T039。
