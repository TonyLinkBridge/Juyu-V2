# T032 · 编辑冲突保护与恢复

日期：2026-09-09。项目 `/Users/tony/Documents/ChatGPT/Juyu V2`。授权来自既有 T032 范围与用户“下一步”；第一版继续不接 Liveblocks。

## 本地实现

保留 T031 的事务序号检查、精确重试、单次发送及待审冻结规则。本轮增加保存恢复面板：保存失败后，原输入仍在编辑区，并提供完整可复制的页面内备份。复制失败会显示手动选择文字的备用方式，不报告复制成功。

管理员可按需读取服务器最新版本。读取继续使用现有 Admin 授权 GET，不写资料；客户端核对文章 ID、版本号不得低于已确认版本、工作状态、正文、标签、封面与文件列表结构。对照区展示标题、版本、状态、类型、阅读范围、标签、封面说明和正文文字；图片、影片和文件只显示说明，不为对照发起媒体读取。

选择“保留备份并载入此版本”需要明确确认。取消不改变编辑区；确认后使用读到的服务器版本重新初始化编辑器，载入前的完整标题、类型、范围、原始标签输入、封面和原始 BlockNote 节点保留在父组件备份区。连续恢复保留多份输入。之后的保存继续核对服务器序号；若别人再次更新，会再次冲突，不自动合并或覆盖。载入待审或停用资料会锁定编辑。

页面存在恢复备份时，即使新的编辑已保存，离开或刷新仍会提醒。备份仅保留在当前页面内，不写 localStorage 或其他持久存储；关闭、刷新后消失，界面已明确说明。用户可复制后手动整理，目前没有备份导入或自动合并功能。
