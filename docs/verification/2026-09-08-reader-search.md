# T020 顶部搜索与结果页：本地验收

日期：2026-09-08

## 交付与范围

改编 GitBook 的五个搜索组件，在已开通员工页提供顶部搜索框和 q 参数结果页。当前只匹配员工已授权目录中的正式文章标题，空格分词要求每个词都出现，中文为字面匹配、ASCII 英文不区分大小写；不是正文全文检索或语义检索。

结果显示文章图标、已授权分类路径、标题高亮、总数量和分页，每页20条；沿用目录顺序并按文章ID去重。结果链接进入现有正式阅读链路，重新核验权限。原生 GET 表单支持回车/按钮、浏览器历史/刷新，Tab/Enter 操作结果链接，Cmd/Ctrl K 聚焦、清空/Escape、中文组合输入、等待状态；没有弹出列表，所以不冒用 listbox/option 语义。

空白查询、零结果、错误条件、越界页和服务失败分别提示。服务失败不伪装成“找到0篇”，有重试入口。查询最多120个UTF-16代码单元；超长输入保留原文并明确提示，不静默截断；服务端也拒绝超长、多值和控制字符参数。分页参数只接受1至999999的十进制正整数。

AuthorizationService.search 在受限的 REPEATABLE READ READ ONLY 事务中读取现有已授权正式目录，再匹配、计数及分页。Support 无 OPS 标题或分类名；Ops 可以；Admin 的阅读搜索也不包含草稿。新草稿不改变旧正式标题，分类祖先限制/停用、角色降级、文章下线后新请求同步收回结果。结果不输出正文、附件、审核状态或后台版本。无新增公开演示路由、缓存或供应商请求。
