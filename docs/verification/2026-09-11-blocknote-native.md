# BlockNote 原生编辑体验验收

日期：2026-09-11。范围：本地源码及隔离测试，未发布线上。

## 实现

以已安装的 BlockNote 0.54.0 原生组件为基准，恢复全部 14 种默认块、原生浮动格式工具栏、侧边拖动菜单、斜杠菜单、链接、颜色、富文本粘贴和撤销。保留 JUYU 的提示框、分页标签、数学公式及流程图扩展。

新增六级标题、折叠标题／列表、待办、引用、分隔线；原生表格支持单元格合并／拆分、颜色、表头及列宽。图片、影片、音频和文件使用原生面板；图片重命名、说明、缩放均完成浏览器保存／重开检查。代码框支持语言选择和延迟加载的官方语法高亮扩展。编号列表保留 0 和负数起始编号。

服务器校验、阅读器、审核／历史预览、搜索提取、Reference 表格和 PDF 均同步接受原生结构。旧内容仅在可编辑副本中转换；已有正式版与历史快照不被改写。

## 明确边界

原生基础编辑体验不等于 BlockNote 网站的所有可选插件、AI、实时协作或评论服务；此次未接入这些额外服务。仍保留内部资料库的安全边界：文件必须经过私有上传和授权读取，外部 URL 可以作为文字链接，不能直接嵌入未受控附件。原有容量和文档大小上限继续有效。

手机验证使用浏览器手机视口，不等同于真实 iPhone／Android 触屏验收。真实 Clerk／Supabase 账号及线上部署验收不在本轮本地结果中。
