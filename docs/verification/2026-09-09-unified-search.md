# T041 统一搜索与权限过滤（本地验收记录）

## 实现范围

沿用GitBook派生的顶部搜索、结果页、面包屑、高亮和原生阅读链接。在同一搜索中检索知识文章、OPS Internal、Reference、Q&A的正式标题、标签和可见正文，展示资料类型、正式版本、正式标签和匹配附近的纯文字摘要。多个空格分隔关键词必须都命中，支持中文短词、ASCII大小写及字面部分词；不做语义、模糊纠错或拼音搜索。

保留120字符输入限制、重复参数拒绝、中文输入法处理、快捷键、20条分页、真实数量、超出页码返回第一页、无结果及失败的独立状态。摘要最长242个UTF-16单元（含省略号），不切坏emoji；所有显示内容均由React文字节点转义。

## 正式版本与权限

0014迁移为每份不可变修订同步建立私有检索投影，补建旧资料投影。原生GIN索引以1/2/3字符字组缩小候选，仍须逐词字面匹配；没有新增外部搜索服务、数据库扩展或依赖。选此方案是为了短中文也有索引候选，不是因为本地无法使用pg_trgm：临时测试库已确认该扩展可用。

投影表不向runtime/context issuer/PUBLIC开放读写。受限搜索函数按当前正式指针、当前身份及can_read_revision过滤后才计算数量和分页。结果路径取自同事务内的授权目录；不一致就报加载失败。点击后的阅读、附件和PDF仍重新校验当前权限。

Support不能搜到OPS；Ops不能读取仅Admin资料；分类祖先限制、停用/降级及成员操作待处理状态同样生效。新草稿已经建索引不代表可被员工搜到：二审并发布后正式指针才切换。旧正式版在改稿期间继续可搜；下线、归档、回收站会阻断后续搜索，永久删除级联清理检索投影。

## 文本提取边界

BlockNote相邻文字样式片段按显示顺序拼接，支持嵌套文字、提示、代码文本、分页标题/正文、表格字段及媒体说明。不会把内部block/asset ID、存储位置或整个JSON当作正文检索。数学/流程图检索说明文字，不索引原始渲染源码。不会提取图片文字、影片声音或PDF/附件文件内部内容；这些文件的访问控制仍按所属文章执行。

独立审查提出的旧格式正文跨强调样式漏搜已修复并通过复审。新增实际搜索回归与13项inline、5项block案例对照现有阅读器解析结果，保留代码围栏和表格单元的字面文字。Hint/Tabs/媒体表格在现有阅读器中直接按文字显示，故保留其中原有符号。
