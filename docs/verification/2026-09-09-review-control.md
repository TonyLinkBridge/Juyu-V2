# T036 撤回审核与更换二审人（本地验收）

## 本轮范围

审核页提供独立“管理本次审核”入口。有效管理员可在文章仍处于等待审核时撤回或更换二审人。撤回将工作状态恢复为未发布草稿；更换保留送审版本和原提交人。两种操作都不更改员工当前可读的旧正式版。

旧二审人停用、降级或待同步时有明确提示，仍可由其他有效管理员处理。新的二审人必须是合格且独立的管理员，排除操作者、原提交人、当前版本作者/编辑者及原二审人；无候选人时不能强行改派。已批准、退回、发布或停用的文章不开放这些操作。

确认前显示操作影响，确认后校验响应再读取真实状态和历史。未确认结果保留原操作用于精确重试，不允许换人或换操作；明确冲突要求先重新核对。后续读取失败不抹去已确认结果，也不继续操作旧状态。

审计保留操作者、版本及新旧二审ID；界面显示成员名称和最近20条撤回/改派记录，存在更早记录时明确说明。完整历史管理界面仍是T039。
