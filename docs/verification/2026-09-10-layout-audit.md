# 布局与登录检查（2026-09-10）

初次授权为公告与切换优化；Tony 随后批准 A1–A8，并选择第四种登录设计的员工亮版与后台暗版。下方保留初次审查证据；最新实现与检查见文末。代码尚未提交或部署。

## 已修改及验证边界

- 默认“内部资料仅供团队使用”提醒不再常驻。真实权限过滤公告移至页面内容，保留关闭/已读功能。
- 员工页面使用共享外框，集合页切换保留顶部和侧栏；加载占位只显示在内容区。
- 文章页保留自己的文章目录，不额外叠加业务侧栏；PDF 保留独立结构。
- 单次服务器渲染共用成员绑定、菜单与搜索开关读取；新请求仍重新验证。没有跨请求身份有效期缓存，没有删除服务端权限检查。
- 身份读取在占用数据库连接之前完成。菜单和搜索开关共用一次受权限限制的数据事务。
- 预加载仅由鼠标指向/键盘聚焦菜单触发，使用动态页面的默认部分预加载，不在首页一次性预加载全部菜单。
- 增加 member.bind 与 reader.frame 耗时记录，不记录用户身份或密钥。
- 343 项单元检查通过；14 项桌面/手机浏览器检查通过；静态检查和构建通过。浏览器新外框验证使用隔离组件样例，匿名入口验证使用真实本地路由。
- 尚未验证部署后的真实登录用户切换耗时，不能声称线上已经变快。仍须发布后检查真实菜单刷新和路由切换。

## 实际检查顺序

1. 线上员工首页：确认默认提示条跨过侧栏；搜索在顶部和首屏各出现一次；现有内容为空。
2. 线上 OPS：确认切换时整个导航消失；完成加载后正文过窄、标题弱、底部另有退出按钮。
3. 线上内容管理：可以读取当前工作台；顶部和筛选区重复搜索；“工作台”和“内容管理”都指向 /admin；主题控件也重复。
4. 线上自定义表单：功能区域可见；说明文字占较多首屏，空表单时仍铺开两栏；页面外围保留“返回管理后台”“设置变更记录”“退出登录”。
5. 线上后台账号菜单退出：真实点击退出后到 /admin/sign-in，出现管理员登录组件。代码逐页核对后台退出按钮均传 audience="admin"；没有确认存在跳到员工登录页的 bug。
6. 线上员工登录及手机视口：两层登录标题与说明重复，窄卡片过长；手机主操作位置偏低。管理员页有“切换到员工登录”，员工页未提供相反入口。
7. 本地文章预览：三栏阅读结构、面包屑和正文可以显示；这只是示例内容，不能作为真实文章、反馈或 PDF 验收。

## 登录设计建议

保留 Clerk 认证与现有公司/Slack 校验。统一聚域 Logo、字体、输入框、按钮和间距，去掉重复欢迎语及重复标题。员工页标题“登录聚域资料库”，管理员页标题“登录内容管理”；二者使用相同视觉组件但保留 /sign-in 与 /admin/sign-in、登录后 /help-centre 与 /admin 的区别。

把“使用 Slack 登录”作为明显主操作，邮箱登录次要展示，保留简洁的“仅限公司成员”说明。手机优先让标题和登录操作进入首屏。注册策略与是否收起邮箱登录需要单独决定，不在本轮改变身份供应商设置。

## 已批准优化的实施结果

- A1：OPS、Reference 与 Q&A 使用统一集合页标题与留白，宽屏正文不再挤在窄列。
- A2：共享页面内隐藏重复退出区，退出保留在账号菜单；五个设置页的记录入口移到标题旁，继续受未保存输入保护。
- A3：后台移除第二处标题搜索；范围由标签页控制，筛选提交继续保留当前范围。
- A4：合并重复的工作台/内容管理入口；主题控件只保留顶部；审核及设置项的选中状态明确。
- A5：表单说明折叠，空配置显示单面板，创建后才打开编辑面板。
- A6：首页只保留主搜索，其他页面仍有顶部搜索；OPS/Reference/Q&A 使用各自图标和说明。
- A7/A8：正式 /sign-in 与 /admin/sign-in 接入同一个定制登录外框，员工亮版、后台暗版。保留 Clerk SignIn；初始入口突出 Slack，邮箱可展开；后续验证路由显示完整 Clerk 表单。未配置时使用同一外框明确显示服务未连接。
- 没有修改 Clerk 注册策略、公司准入、管理员权限、OAuth 凭据或服务端跳转规则。隐藏初始注册链接不等于禁止注册或授予权限。

验证：343 项单元检查通过；最终受影响页面的 78 项桌面/手机浏览器检查通过；最终构建、静态检查和 diff 检查通过。浏览器测试覆盖表单/字段/分类/开关/导航的保存与输入保护、登录展开/错误/后续步骤展示、固定跳转参数及文章/PDF 外框。登录供应商在组件测试中被模拟，不代表真实 OAuth、MFA 或新成员开通已验收。
