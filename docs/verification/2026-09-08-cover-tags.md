# T024 文章封面和标签：本地版本保存与阅读验收

日期：2026-09-08

## 已交付范围

从 GitBook 的 PageCover、PageCoverImage、PageTags、Tag 及 PageHeader/PageBody 分支适配阅读展示。封面在正文标题区域上方，用原生私有图片请求、原始 1990/480 比例及 0–100 纵向裁切位置；无封面不造默认图片，加载失败显示简短提示且正文保持可读。标签在标题上方以胶囊标签换行，不生成尚未实现的标签检索链接。

版本保存仍使用既有 DocumentRepository create/execute 管道：tags 和 cover 随不可变版本存档，省略字段的普通编辑保留原值，显式空数组/null 清除；变更必须按原二审发布流程生效。正文修改也会复制原版本分类及非 cover 附件，防止丢失受限分类或无意删除附件。历史标题、标签、封面和审计记录不被覆盖。

标签最多12项、每项40个字符，去首尾空白、NFC归一和精确去重；空标签、控制字符、非法形状拒绝。封面仅接受本篇文档已ready的PNG/JPEG/WebP/GIF，保存替代文字及裁切位置；拒绝远程URL、跨文档附件、隔离附件、SVG/活动内容和非法位置。原文件对象不可覆盖的存储规则继续适用。

新增 0006_article_presentation 迁移：revisions 增加标签、替代文字、裁切位置，封面继续使用已有 revision_assets 的 cover 关联。runtime 仅可在新版本审计事件写入前建立版本关系，不可重写已保存/待审版本的关系；assets 的状态 UPDATE 权限仅供行锁，WITH CHECK false 不开放直接改状态。升级不改旧迁移文件。

读取在现有同事务快照中取正式正文及 read_publication_presentation。员工读封面仍走 /api/assets/:id 的实时授权；不经过不转发身份头的 Next 图片优化/公开CDN，不输出存储地址。Support 看不到 OPS/受限分类封面或标签；新草稿不暴露，新版正式发布后旧封面若不再被当前版本引用即不可读取。若仍作为当前版本附件使用，则继续受当前版本权限允许，这是正常保留引用。

## 接入边界与下一步

本项完成本地数据管道与阅读组件，不宣称后台编辑操作已经可用。上传/选择已有文件面板属于T027，BlockNote与封面标签编辑表单属于T031，提交/审核/发布操作界面属于T034–T037。上述保存和二审发布验收目前由测试调用真实仓储完成，未增加临时公开写入API或登录绕过页。

T031需提供显式移除/替换封面：旧封面如果已被隔离，携带该封面的新草稿保存会拒绝，不能静默丢弃或忽略校验。图片替代文字允许空字符串表示装饰图；有业务意义的图片需管理员提供说明。第一版只支持单图hero封面，不包含上游全幅背景、暗色专用图、默认封面或拖拽裁切编辑器。

真实 Clerk、Supabase、公司域名/Workspace 配置及真机验收仍待准备；迁移只在临时测试库运行，没有修改真实账号、真实存储或部署。下一项为 T025 文章有帮助吗反馈。
