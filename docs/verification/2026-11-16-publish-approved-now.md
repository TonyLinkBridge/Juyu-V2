# 已批准资料立即发布与状态列验收

## 行为与边界
- 四类资料在 approved/queued 均有“立即发布”。列表/看板入口只打开确认页，确认后才写入；打开、刷新、取消不自动发布。
- 已批准资料使用 publish_now，在既有事务里复用 queue→publish；等待发布继续使用既有 publish。审批凭据和正文版本不重建，原 API 仍兼容。
- 既有角色、有效批准、文件、精确序列检查保留。失败回滚等待发布、正式版、审计与通知；精确重试不重复发布。
- 仅等待发布的次要操作仍保留。无效批准、草稿、已发布或非活动资料不会因 URL intent 参数而开放发布。
- 桌面表格明确分配标题/状态/时间/操作列，邮箱正常换行，状态保持一行；窄屏使用可滚动表格，移动端卡片布局保持不变。
