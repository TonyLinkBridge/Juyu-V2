## 交付行为

- 实际适配指定 GitBook 的 PageGroupItem 和 PagesList group 分支，支持多层分类展开、收起、缩进及当前文章高亮。
- 分类按已保存 position 排列，同值以稳定 ID 排序；各层先子分类、后文章，文章按标题和 ID 稳定排序。后台编辑排序入口属于 T049。
- 分组默认展开；刷新/重新导航后展开当前路径并沿用 T017 当前项滚动定位。折叠内容用 hidden 排除键盘和辅助技术访问，按钮有唯一控制关系。
- 重命名不影响分类 ID 或正式文章关联。多分类文章按确定目录顺序只显示一次，但权限仍检查它全部的正式分类。
- 仅正式已发布版本的分类归属进入目录。无权、禁用、归档/删除及草稿内容不输出；空组裁剪，循环/缺失祖先不将文章放回根目录。
- 同一受限只读事务取得标题、正式分类关联及允许分类；服务端先裁剪再交给组件。真实员工页与目录 API 已接入树。
