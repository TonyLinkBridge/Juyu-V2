# T043 Q&A 问答管理（本地验收记录）

## 功能与版本边界

员工新增 `/help-centre/qa` 入口；列表只包含当前有权查阅的已发布 Q&A。每条记录以问题为标题，打开后沿用 GitBook 派生正式阅读区查看完整答案。列表不返回正文或私有附件信息；原有搜索、附件及 PDF 路由继续各自核对当前权限和正式版本。

可输入完整问答分类，或点击已有分类查看同类问题；不带分类条件表示全部，提交空输入或点击“未分类”会筛选未分类问题。分类按完整名称区分大小写，页面输入会去掉两端空白。排序数字越小越靠前，同值按问题标题和 ID 稳定排序；每页20条，数量与分页基于权限过滤后的结果。无内容、无匹配分类、权限不足与读取失败分别显示，不替换成虚构业务答案。

Admin 可以从问答列表新建或编辑。BlockNote 沿用既有正文编辑、保存冲突处理、删除、独立二审、批准、等待发布、正式发布及完整历史流程；Support/Ops只读。新建入口预选Q&A，已有内容的资料类型不会被入口参数改变。

问答分类与排序作为不可变版本元数据，随草稿保存并显示在二审、发布核对、服务器版本对照和历史来源页。已发布问答再次修改时，旧答案、旧分类和旧排序保持可读，直到新版通过独立二审并正式发布；恢复历史内容建立新草稿，也恢复来源分类和排序，不替换当前正式版。

## 权限与数据约束

问答分类只用于查找，不改变既有阅读权限。公司成员绑定、当前角色、停用状态、阅读范围、权限分类及其祖先限制继续参与校验。请求携带的伪造角色无效。新的0016迁移提供受限正式问答元数据投影，不扩大既有原始资料表权限。

应用输入/领域写入限制：分类最多80个Unicode码点、去两端空白、不含控制字符；排序为0到999999的整数。非Q&A内容不能通过应用写入有意义的问答字段。SQL CHECK校验值的形状和范围，不新增跨资料类型触发器；本轮没有扩张既有原始数据库写权限。

省略问答字段的旧客户端保存会保留已有元数据，显式字段参与重试一致性核对；在审版本继续冻结。页面内输入备份保留分类与排序，包括尚未通过校验的输入。
