# 筛选、复制与使用指南验收

日期：2026-10-08。范围：UIArc FilterToolbar、Cult CopyButton、Cult Onboarding 三项生产接线。

## 实际接入

- 内容管理：`TasksFilters` 使用官方 UIArc FilterToolbar，沿用服务器的标题、资料类型、状态、范围、看板/列表查询。添加、移除或清空条件均重置到第一页；清空仍保留资料类型与显示方式。原生 GET 表单与无脚本清除入口保留。
- 编辑与恢复：`ArticleEditor` 的「复制当前输入」和 `InputBackup` 的「复制这份备份」使用 Cult CopyButton。复制整份当前序列化输入，包含未保存正文与元数据；成功等待剪贴板确认，失败保留原文和手动复制入口。备用复制在当前原生弹窗内选择文字，避免弹窗外内容被设为 inert 后无法聚焦。
- 使用指南：已登录账号菜单添加「使用指南」，手动开启，可反复查看。员工介绍分类、可用的搜索、阅读、收藏和反馈；后台介绍筛选、编辑、保存与审核发布。管理员与 Super Admin 的发布说明分别对应现有权限。
- 功能开关：每次开启读取既有 `/api/features`，失败可重试，关闭的可选功能不进入指南。后台指南角色来自现有服务端账号读取。指南不提交、审核或发布内容，跳转沿用编辑离开保护。
- 视觉：使用 JUYU 现有字体、红灰颜色和按钮样式；保持 Fumadocs 阅读端复制控件及账号菜单原有设置/登出操作。
