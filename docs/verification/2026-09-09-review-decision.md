# T035 指定二审批准、退回与重提（本地验收）

## 本轮范围

独立审核页只读展示当前文章内容及审核记录。只有当前被指定、仍具有效管理员资格且未参与撰写该送审版本的二审人可以决定。其他管理员可以查看资料与原因，但不能代替指定二审人作出决定。

批准需要明确确认；退回必须填写原因，最多2000字符。批准后才进入“已经批准”，不会自动进入发布或覆盖员工的旧正式版。退回保留原因，修改保存形成新草稿后才能重提；退回原稿不能直接原样重提。审核记录与工作版本不同时明确标出记录对应的版本。

决定与审核记录、审计在同一事务中完成，并核对版本与当前权限。相同原请求的重试不能生成重复决定；冲突或不能确认的结果不会在页面显示成功。网络异常保留退回输入，支持原请求重试。不得在结果未知时改成另一个决定。
