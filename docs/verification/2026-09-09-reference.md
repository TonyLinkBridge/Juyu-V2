# T042 Reference速查表与编辑（本地验收）

## 完成范围

新增 `/help-centre/reference` 正式速查资料入口和私有读取API，Support/Ops/Admin均按当前权限查阅。集合每页20篇，按正式标题/ID稳定排序，有真实计数；选择一篇后跳到其正式表格区域。表格支持中文/ASCII字面多关键词、指定列、清除筛选、原行号及每页20行；各表筛选状态独立，不改动原始资料。

展示旧格式正文表格、旧媒体表格及BlockNote混排表格，沿用阅读器解析顺序，避免双重计入媒体块。没有表格、没有数据行、无筛选结果、无权或读取失败分别呈现。文本安全转义，手机表格使用有名称且可聚焦的横向滚动区域，页面本身不横向溢出。

管理员看到新建和编辑入口；新建Reference预选资料类型，已有文章的类型不被入口参数覆盖。编辑继续使用BlockNote、自动保存、独立二审、批准/等待发布/发布及历史记录，不新增直接修改正式表格的接口。Support/Ops仍只读。

## 权限与正式版本

0015迁移只提供受限正式Reference元数据投影，不扩大资料表策略或PUBLIC权限。读取集合和表格都要求当前已绑定公司成员，类别、正文阅读范围、分类祖先及当前正式版本继续参与权限检查。停用、降级或成员操作待处理不能用旧身份继续获取表格。

集合不返回表格内容；详情只返回选定Reference的正式表格，不返回全文、其他内容块、存储位置或私有附件ID。新草稿继续走审核发布；正式表格在新版发布前保持原样。归档、下线、删除会阻断后续Reference/全文/PDF访问；永久删除沿用现有清理。

本地筛选操作只作用于已经授权传到设备的表格，不是权限边界，也不能撤回设备已收到的内容。阅读全文和PDF请求各自重新校验当前权限与版本。界面明确PDF包含完整正式文章，不暗示导出筛选后的行。
