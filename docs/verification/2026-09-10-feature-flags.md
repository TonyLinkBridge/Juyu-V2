# T052 功能开关本地验收 · 2026-09-10

## 交付范围
管理员通过 `/admin/settings/features` 管理七个固定功能：搜索、文章 PDF 阅读/导出、收藏、最近浏览、文章反馈、使用分析、内部表单。新系统未保存配置时默认全部开启；读取失败或异常配置不会伪装成默认值。仅管理员可以读取完整配置和保存，员工接口只返回七个布尔值。

关闭对所有角色生效，隐藏页面入口/正文控件，并在相关服务端业务操作的数据库事务内检查当前开关。关闭不删除或重建数据；重新开启使用保留记录。表单开关包括填写、配置、提交记录和处理。分析关闭不影响独立收藏、最近浏览；暂停期间的分析事件不会在恢复后补录。

登录、成员权限、正常文章阅读以及功能管理入口保留。菜单隐藏不改变内容权限。PDF 开关仅控制应用内文章 PDF 页面与生成；原始 PDF 附件仍受原附件权限控制，浏览器原生打印也不由开关控制。

## 保存与并发边界
固定七布尔完整配置、整体版本比较、同一管理员相同请求准确重试、不可变配置历史。保存先展示影响确认，未知结果锁定原请求；冲突、失败载入及多次重新载入保留输入/累积备份，恢复备份只放回编辑区，仍需确认保存。未保存或未确认结果有离开保护。

业务操作持有共享事务锁，配置写入持有独占锁；已受理操作可以完成，关闭提交后的新操作拒绝。已经打开的页面可能保留旧控件，刷新后隐藏，服务端仍按当前配置执行。PDF 生成后再次检查当前开关，关闭时不发出生成文件。这里不是向已打开页面推送关闭，也不撤回已下载文件。

检查入口位于应用服务和仓储；不声称对拥有数据库凭据的运维 SQL 实施全局功能禁用。原有角色、发布版本、分类与私有附件检查继续生效。
