## 本轮功能

管理员工作台的内容工具新增使用分析入口 `/admin/analytics`，只读 API 为 `/api/admin/analytics`。支持最近7、30、90天，默认30天，时间筛选和刷新通过服务器重新读取。四项概览为搜索结果页展示、零结果展示及占比、搜索点击率和当前可读资料打开次数；下方显示热门搜索分组、零结果分组、热门资料和需要改进资料，每类最多前10项。时间在页面显示为UTC+8。

未配置、读取失败、无权和无数据分开处理；失败没有零统计或旧数据。真实站点没有测试登录或演示统计。浏览器成功页面使用明确标注的本地组件样例。

## 统计口径与隐私

后端在只读repeatable-read事务中重新核对当前数据库身份、Admin角色、有效成员和已观测的非空验证邮箱。沿用当前身份函数对停用、开通及角色同步状态的检查；两次SELECT处于同一快照。所有计数和榜单共用数据库事务时间，精确回溯7/30/90个24小时，起止包含、未来排除。读取无业务写入，API private/no-store。

搜索按采集成功的结果页展示计数，分页会增加展示；不是独立搜索会话。点击率分子为所选时间内有点击的不同展示编号，分母为该时间内所有展示；一次展示多次点击不抬高分子，点击总次数另列。点击必须与同时间范围的搜索及同成员关联。没有展示时比例显示“—”，有展示但无点击才是0%。

延续T046的保守设置：只存规范化关键词的SHA-256指纹，页面以缩短标识分组，完整指纹在标题属性中。没有关键词原文，因此不能识别具体热门词或具体零结果问题，也不能据此声称已经知道员工找不到什么。此前隐私选择尚未得到答复；哈希不等于匿名化。搜索榜单保留历史指纹和数量，不返回结果标题、摘要、评论、成员标识、邮箱或事件明细。

热门资料只列当前仍可读的活动正式资料，显示最新正式标题和版本；次数合计所选时间内该资料各版本的view。下线/归档、删除和不可读分类资料不计入这个概览及榜单，所以不是所有历史访问总量。草稿标题不会出现在榜单。

负反馈读取当前正式版本的当前feedback行，最后修改时间在所选范围内。每员工每版本一份；负评改好评后仅剩好评，旧正式版本反馈不算进当前负评榜；不把反馈变化事件当成多个员工。榜单使用负评数排序，总量与负评占比共用同一范围。每类榜单有固定并列排序规则，概览总量不受前10名限制。

采集是尽力记录的样本，可能漏报，打开资料不是已读完的证明。当前没有原始查询词、趋势对比、每员工行为报表或分析导出。
