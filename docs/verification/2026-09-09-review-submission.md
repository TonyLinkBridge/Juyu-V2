# T034 选择二审管理员并提交（本地验收）

## 本轮范围

在已保存的编辑页面主动打开二审选择，读取当前有效管理员名单，明确选择后提交。名单排除提交人、当前版本作者和最后编辑者，并分页提供其他候选人。没有候选人与读取失败是不同状态。未保存、正在保存、上传、删除及已停用/待审资料不可直接提交。

服务器不接受客户端传来的角色；在事务中核查当前管理员、候选人资格、版本序号和文章状态。提交冻结已有工作版本，记录提交人与二审人，不创建已批准状态，也不更改原正式版本。重复请求须符合相同提交人、二审人和原事务序号才能得到原提交结果，不能增加重复审核或审计。

提交响应丢失或无法确认时，保留当前输入并锁定修改，支持原请求重试。收到核对一致的成功响应后，界面显示等待审核并保持版本锁定。本轮不包含批准、退回、撤回、更换二审或发布操作；这些按后续代办接入。

## 真实服务边界

测试只使用独立本地数据库和带标识的浏览器组件样例；实际未配置接口保持关闭。不提供演示登录、认证旁路或生产样例资料。Clerk、Supabase、公司邮箱和Slack Workspace允许列表、真机与部署的联合验收仍待准备。

候选人资格依据系统已同步的角色和公司准入状态，不能把本地角色检查当作每次都实时读取Clerk角色的证据。服务集成阶段仍须验证角色变更、成员停用及同步失败的实际行为。

本轮不改变PDF渲染，也不把之前的实际PDF生成测试计为本轮测试。
