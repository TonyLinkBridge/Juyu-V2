# T038 已发布改稿、归档和下线（本地验收）

## 完成范围

编辑器补充新旧版本说明及归档/下线入口。现有正式资料修改后保存为新草稿，员工继续阅读旧正式版本；新稿必须再次提交给独立管理员二审，经批准、等待发布、明确发布后才能替换。

下线仅对存在正式版的工作台资料开放；下线后留在工作台草稿。归档对工作台资料开放；归档后进入独立分页列表，员工无法读取。两种操作都清除正式版指针、结束待审记录并清除当前批准，保留正文版本、文件和历史。归档恢复只回到未发布草稿，不复用旧批准，也不自动上线。回收站和永久删除仍沿用T033。

有效管理员可查看归档列表、工作版本与原正式版本记录。归档列表每页30篇，操作历史最近20条，并明确是否有更早记录。操作必须确认影响，响应核对文档、版本、状态及正式版移除；未知结果保留原请求精确重试，明确拒绝后重新读取，确认成功后的读取失败不会被说成操作失败。

## 权限和数据

新增0011数据库迁移及受控归档/下线命令，旧迁移原样保留。命令在同一事务完成角色复查、版本冲突检查、审核撤回、正式指针移除和审计；运行账号不能伪造生命周期授权，也不能直接插入已归档资料。审计新增原正式版字段，并保留历史行。

新请求按当前正式指针重新检查正文、导航、搜索、收藏、最近浏览、附件和PDF。私有响应保持no-store。附件等待存储响应后，在向用户发送完整文件或分段字节前再次授权；权限失效、文件信息变化或错误均取消响应流。PDF生成既有流程会在发送前再次核对正式版本与权限，本轮不改渲染器。
