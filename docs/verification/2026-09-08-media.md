# T027 图片、影片、文件和表格 · 本地验收

2026-09-08。本地媒体编辑与阅读实现完成；真实 Clerk/Supabase、公司准入配置、真机和部署验收仍待办。没有真实账号写入、云端迁移或部署。

## 行为及范围

Admin 后台新增 `/admin/media`，选择已有资料后上传本篇文件、设封面、加入图片/影片/下载文件、编辑表格内容、调整块顺序与移除。表格支持1–8列、最多200行，保留中文、多行和空单元格。不支持合并单元格或嵌套块。当前内容块按顺序放在基础正文之后；完整 BlockNote 和任意正文位置编排仍为 T031，新文章工作台入口为 T030。删除按钮移除待保存的块，不物理删除历史文件。

保存仅提交 expectedSequence、blocks 和 cover。服务端用当前成员检查 Admin、文章状态与版本号；事务创建新草稿修订、重建块文件关联、保留分类和其他独立附件关系。旧正式版本继续可读，只有独立二审及发布后替换。审核中的内容不可编辑。删除块的新稿正式发布后，该块若没有其他当前正式关系，员工不能再从旧链接读取；历史记录仍保留。普通正文编辑未传 blocks 时保留已有块。

阅读端显示私有图片、原生播放器、文件打开/下载按钮与可横向滚动的结构化表格。无外链嵌入、公开对象地址或图片优化公共缓存。图片/影片失败有文字提示；影片文字说明可编辑，但尚未接入字幕文件。下载已读取的文件无法远程追回，不宣称 DRM。

## 上传及权限

PNG/JPEG/GIF/WebP ≤5 MiB；MP4/WebM ≤50 MiB；PDF ≤20 MiB；UTF-8 TXT/CSV ≤5 MiB。检查扩展名、文件头/编码及实际字节大小，拒绝HTML/SVG与未知类型。文件头检查不是完整解码或病毒扫描。

必须同源且当前 Admin；接收正文前检查文章。预留 pending 元数据及不可变上传事件，用随机UUID对象键禁止覆盖，私有写入后读回、核对长度与SHA-256，再标为ready。失败尝试隔离；若身份撤销或操作未确认，可能保留pending/孤立对象，不能加入正文，清理任务待后续。每进程最多2项上传操作，全程90秒；不宣称多副本全局限流。

所有正文文件必须属于本篇、ready且类型匹配，关系在事务中锁定。Admin草稿附件使用独立授权端点，Support/Ops不能借该端点读草稿。员工附件仍要求当前正式关联与角色/分类授权。真实 Supabase 存储尚未连接，本次仅在回环HTTP私有存储夹具验证适配器。

## PDF

正式文章PDF加入正文图片和结构化表格；文件/影片只保留说明文字，不把附件字节或可播放影片嵌入PDF。所有引用的媒体在生成前后复核权限，打印检查也覆盖所有块。图片逐项最多5MiB、合计20MiB，正文与块合计25万字符；坏图拒绝出缺图PDF。

实际 Chromium 生成 `output/pdf/T027-media-verification.pdf`，1页、1张正文图片，中文多行表格及影片/文件说明提取检查通过，Poppler栅格化后肉眼检查无裁切/重叠/缺字。T026原有140行多页PDF回归保持通过。样例仅为合成测试资料。
