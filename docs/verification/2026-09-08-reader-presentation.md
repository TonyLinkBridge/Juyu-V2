# T023 深浅色模式、公告栏与页脚：本地验收

日期：2026-09-08

## 已交付

沿用 GitBook ThemeToggler 的浅色、跟随系统、深色三选一结构，使用原生 radio 支持键盘方向键；页脚保留品牌说明、访问说明及主题控制。主题用于现有阅读、搜索、登录、管理入口和本地管理组件的共享样式。区分深色模式的文字强调色与按钮底色，避免浅色文字落在浅粉按钮上。

首次绘制前的常量脚本读取主题偏好；跟随系统时响应系统变化，显式选择不受系统覆盖，跨标签页同步。无效偏好回到系统；浏览器禁止存储时本页仍可切换，无法保证跨刷新记忆。无 JavaScript 时基础 CSS 跟随系统，交互切换与公告需 JavaScript。

公告采用 GitBook 的提示图标、消息、关闭按钮和 data-nosnippet 结构。当前唯一正式配置是通用提醒“内部资料仅供团队使用，请以已发布内容为准。”，仅在成员准入成功且阅读服务正常返回后传入，不在登录、拒绝、未开通或服务失败界面显示。它不是后台公告发布系统；T054 才处理管理员编辑、按角色发送及新功能通知。

公告关闭按 ID 和版本记忆，刷新继续隐藏，新版本重新出现；关闭后焦点转移到主内容。浏览器只保存偏好及关闭标记，不保存消息内容、身份或业务资料。服务端快照不展示公告，避免已关闭公告刷新闪现；hydration 后再显示未关闭公告。

ReaderChrome 测量顶部实际高度，目录及右侧小目录按剩余视口调整。真实组件 SSR 快照到 hydration 的测试复现了公告出现后当前目录末项被裁切，现由 ScrollContainer 尺寸观察重新定位解决，不在正常滚动时重置位置。
