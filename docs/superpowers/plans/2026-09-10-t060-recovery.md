# T060 recovery implementation

Scope: isolated local recovery first; never load .env or accept a production database URL in the drill.

1. Use official pg_dump/pg_restore against two generated temporary PostgreSQL clusters.
2. Seed published staff/OPS documents, a pending revision, and linked private media; archive all juyu tables except ephemeral request contexts, plus migration sources/checksums and media bytes.
3. Restore into the empty target, compare every table and sequence, verify migration checksums, restricted-role reading and private media integrity. Exercise corrupt media refusal.
4. Document operator health gates, paired backup procedure and application rollback. Do not present a local fixture as Supabase cloud or Vercel rollback acceptance.
5. Run the drill, lint and typecheck. Record evidence and keep T060 partial until isolated cloud restore and actual release rollback acceptance exist.
