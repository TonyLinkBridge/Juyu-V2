# T056 两管理员连续流程本地演练

按既有批准需求执行，不添加新产品规则或登录旁路；当前助手直接操作及自查。

1. 使用隔离真实PostgreSQL及受限生产连接，A/B独立可信测试身份；另设未被指定的C及Support/Ops观察者。
2. 同一篇BlockNote文章经保存、真实本地HTTP上传私有封面、选择B、禁止A/C审批、B退回、修改重提、B批准、排队、发布。每一步核对工作台计数与员工可见正式版本。
3. 发布后改稿重新审核，旧正式版本持续可读；删除时所有员工入口下线；恢复只回草稿，重新二审发布；历史版本恢复也重新审核。
4. 检查错误操作不改变版本/审核/日志、准确重试不重复记录、旧版本和退回理由保留、当前数据库状态与审计事件一一对应；保存机器可读演练轨迹。
5. 运行新连续演练及相关完整数据库回归、类型/lint；若产品改动则追加构建和相关浏览器回归。
6. 编写真实账号逐步验收表，明确当前未配置、不得把本地结果签成真实通过；更新T056本地进度并衔接T057。
