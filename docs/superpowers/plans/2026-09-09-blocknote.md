# T031 BlockNote 编辑器实施计划

授权：既有设计、TASKS.md T031，用户本轮“下一步”。使用既有独立 Juyu V2 目录，不访问真实服务或修改原始来源目录。

目标：新建/编辑文章、自动保存与重试、离开提醒、冲突不覆盖，编辑/阅读/PDF使用同一份有顺序的文档。

1. 文档适配：src/editor/document.ts 规范 BlockNote 节点；旧文字和已有媒体转为编辑节点；正文以 JUYU_BLOCKNOTE_V1 前缀序列化，数据库已有不可变 body 保存；content_blocks 为服务端计算的媒体投影，继续维护私有附件关系。限制300节点、8层、40媒体块、750k序列化长度；只启用已适配的节点/文字样式，拒绝未知结构。
2. 保存服务：Admin GET/PUT编辑入口；body/标题/范围/标签/封面规范化；序号检查、同内容同作者精确重试、待审禁止编辑；从提交事务返回确认，不能以稍后读取其他人的版本作为保存成功。
3. 编辑界面：BlockNote 0.54.0、本地依赖，无Liveblocks。文字、标题、列表和已有富内容块可混排；原有上传接口和私有预览；标题/标签/类型/范围/封面；新建首存生成稳定ID后进入已有文档。1.2秒停止输入后自动保存，正在发送时的后续修改保持待保存，错误停止自动重试并保留输入；明确手动重试、版本冲突、离开提醒、复制未保存内容。
4. 阅读/PDF：不重复追加媒体投影；保持嵌套、标记、图形/表格与顺序，旧文本资料兼容。管理员草稿预览不触碰正式指针；草稿不是员工可读内容。
5. 验证：文档规范化、恶意/超限输入；实际受限数据库新建/重试/冲突/权限/二审冻结；实际BlockNote浏览器编辑/自动保存/保存中输入/失败重试/退出提醒/手机；PDF混排；构建类型lint，全量回归；独立复核、来源记录与TASKS更新。

分工：editor_document 负责文档/阅读/PDF；review_cover_tags 负责本轮保存服务（重新分配）；主任务负责编辑界面与自动保存控制器、集成和验收。无Git仓库，保留计划与验收文件，不创建或删除工作树。

范围说明：第一版不启用多人协作、外部图片URL或任意HTML。二审/发布操作面板仍按T034起接入；编辑保存不等于发布。T032继续完善冲突恢复交互。真账号、真机和部署验收仍待配置。
