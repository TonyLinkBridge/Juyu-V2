# T019 正文阅读区与本页目录

执行已批准 T019。真实 GitBook PageBody、PageAside、ScrollSectionsList、Heading、Paragraph 和 DocumentView 的基础阅读分支作为来源。替换 GitBook API/上下文，不接广告、AI、公开导出、外部预览或供应商统计。

现有正文为 string。T019 定义安全文本适配：段落、# 至 ### 标题、顶层有序/无序列表；其余文本保留原文，包括 HTML/链接/媒体语法，不执行或请求外部资源。不是完整 Markdown 或 BlockNote 渲染器，T027–T031 继续适配复杂块。标题生成唯一确定 ID，正文和目录共用同一解析结果；重复中文标题也能区分。

授权：新增 reader(requested) 在同一受限只读事务取得目录树与当前正式正文，只允许选中已授权目录中的 ID。返回 id/title/revision/body；不接收请求角色或版本号。未登录/权限撤销/下线/草稿仍无法读。主页一次读取该快照，避免不同版本的导航与正文混合。

布局：电脑左目录/中央正文/右本页目录；窄屏本页目录作为正文前的可展开入口。基础标题和段落按 GitBook 结构适配；点击锚点、滚动高亮、刷新深链接均验收。无标题不伪造目录；空正文明确提示。
