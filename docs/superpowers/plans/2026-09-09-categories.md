# T049 分类设置

目标：管理员可创建、重命名、移动、排序、停用分类并设置 staff / ops / admin 范围；文章通过固定 UUID 归属分类；父级限制继承，循环拒绝；员工搜索、阅读、文件和 PDF 统一受当前分类权限约束。

## 决策

- Ruling: 本阶段补上编辑器分类选择，因为只有设置页无法让管理员实际整理文章。分类归属跟随文章版本，修改草稿不改变旧正式版本。
- Ruling: 分类设置是即时访问策略，移动、范围或停用影响现有正式内容。设置页明确提示；分类不可硬删除。
- Ruling: 最多 100 个分类（含停用）、10 层、每篇最多 20 个分类；多个分类共同限制访问。使用版本冲突检测、准确重试和操作历史。
- Ruling: 用户已授权下一步，本地现有目录直接修改；无 Git，不创建 worktree 或提交。源代码基线位于 /private/tmp/juyu-t049/baseline。真实 Clerk / Supabase 验收仍待配置。
