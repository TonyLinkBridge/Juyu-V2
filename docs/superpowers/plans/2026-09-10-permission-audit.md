# T055 自动化权限与越权核查

按已接受的三角色和正式版本规则，由当前助手直接实现及自查，不使用subagent。

1. 固定接口/页面清单；所有业务方法必须在未配置身份时拒绝伪造Cookie、Header、查询角色，并禁止缓存。
2. 在隔离真实PostgreSQL用生产受限连接创建普通、OPS、管理员范围、未发布资料及附件；逐角色核对正文、目录、搜索数量/摘要、私有图片/媒体/文件、PDF、收藏与最近浏览。
3. 全面检查员工不能调用管理方法；覆盖已打开服务降权、成员停用、旧稿保留和权限撤销后文件/PDF释放前再检查。沿用既有并发编辑、二审、历史、表单及设置测试。
4. 核查Next图片优化入口与私有缓存路径，发现问题先留复现证据再修复；不添加生产登录旁路。
5. 专项、既有单元/数据库/浏览器、构建/类型/lint验证；记录覆盖范围及真实Clerk/Supabase尚未验收的边界，更新任务。

页面正向三角色体验继续由隔离组件及服务测试提供证据；实际配置缺失的网站只验证拒绝访问。真实三角色会话及Supabase直链验收留待测试项目准备。
