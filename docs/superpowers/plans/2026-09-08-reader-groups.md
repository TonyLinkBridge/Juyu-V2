# T018 分组、子目录与排序

按 TASKS.md T018 执行已批准阅读端范围。使用 GitBook PageGroupItem 与 PagesList 的 group 分支，保留已授权服务端边界。后台分类编辑属于 T049，正文属于 T019，手机抽屉属于 T021。

选择：分类 position 升序，相同 position 以稳定 ID 排序；每组先列子分类再列文章，文章沿用标题及 ID 稳定排序。多分类文章只在目录顺序最前的所属分类出现一次，但权限仍检查所有正式版本分类。未分类文章保留根列表。没有可读后代的分组不输出。循环、缺失祖先的目录路径拒绝，不将文章降级到根目录。重命名保留稳定 ID 和文章关联。

架构：新增只读 navigationTree，从同一受限事务读取已发布标题、正式分类关联、允许的分类；服务端组装并裁剪目录树。保留 T017 flat navigation 供现有验收。主页与 /api/navigation 使用 tree；前端纯递归选择当前页。折叠按钮有 aria-expanded/controls，折叠后链接不进入键盘顺序。分组默认展开，重新导航/刷新展开当前路径；不在本次保存个人折叠偏好。
