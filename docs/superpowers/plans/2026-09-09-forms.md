# T050 自定义表单

目标：管理员以已有字段配置表单、必填与布局，员工按当前角色填写并提交固定记录，仅管理员处理。没有脚本执行、邮件/Slack/外部动作。

## 决策

- Ruling: 表单与文章工作流独立，Admin保存启用即向指定角色开放，不借用文章二审状态；原文章权限/审核不变。
- Ruling: 最多50个表单（含停用）、每表单1–20字段；字段顺序和 full/half 宽度支持桌面单双栏、手机单栏。
- Ruling: 表单保存字段定义版本快照及独立必填规则；现有字段变更/停用不静默改已配置表单。原绑定可保留，新增/更新绑定需当前启用字段版本。旧提交始终保留当时表单/字段及值。
- Ruling: 员工仅查看当前启用且有权限的表单、提交及收到自己的最小回执；全体记录与处理入口仅Admin。记录状态新提交→处理中/已处理，可由Admin重开为处理中；备注和处理动作有版本与历史。
- Ruling: 提交UUID和配置版本用于准确重试，旧表单首次提交冲突保留输入；已有自己相同提交的回执可重取，不因表单改版制造重复记录。
- Ruling: 沿用本地工程直接修改、无Git；基线 /private/tmp/juyu-t050/baseline。可用协作线程复用为新职责，提供本阶段完整简报，不继承旧任务目标。真实Clerk/Supabase仍未连接。
