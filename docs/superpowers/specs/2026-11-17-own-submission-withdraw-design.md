# Admin 自己送审资料的撤回快捷入口

用户已确认：只在自己提交、仍等待审核的资料行增加「撤回送审」；超级管理员批量撤回独立限制，现有单份管理权限保持不变。

使用原有审核管理页与撤回接口：列表直接链接到自己的撤回确认页，不再需要进入“更多操作”。服务器只在当前登录人为提交人、版本仍在审核且可管理时自动展开确认；打开链接与取消都不写入。确认一次调用原撤回逻辑，保留正文、历史、权限、已有正式版及链接。

不另做一套审批或撤回规则，不新增数据迁移。四种类型和手机列表统一适用。测试验证入口归属、伪造/重复 intent、非审核状态、取消零写入和确认保留正式版。全部用本地测试数据，未授权推送 main。
